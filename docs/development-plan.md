# 开发计划与交付清单

## 一、阶段计划

| 阶段 | 主要工作 | 交付物 | 前置依赖 |
| --- | --- | --- | --- |
| 需求与口径 | 确认观察窗口、字段和预测时点 | 需求、数据字典 | 无 |
| 数据准备 | 采集、清洗、去重、关联标签 | 清洗数据、报告 | 需求与口径 |
| 大数据入湖 | HDFS 目录、权限、文件版本和 HBase 表初始化 | HDFS 数据集、HBase 表和初始化记录 | 数据准备 |
| 特征工程 | 编码、划分和泄漏检查 | Pipeline、数据质量结果 | 清洗数据 |
| 模型训练 | 训练、调参、评估、规则导出 | 模型、指标、规则 | 特征工程 |
| 后端开发 | 封装模型、统计和接口 | FastAPI 服务、OpenAPI | 模型和数据契约 |
| 前端开发 | 页面、图表、状态和联调 | Vue 3 页面 | API 契约 |
| 验收汇报 | 端到端演示和答辩材料 | 测试记录、截图、演示稿 | 全部模块 |

## 三、最小可演示链路

```text
准备订单/退货原始数据
  → 写入 HDFS 原始区
  → 执行清洗、标签构造并写入 HDFS 清洗区
  → 将订单级数据写入 HBase
  → 从 HDFS 训练决策树
  → 写入 HDFS 模型产物和 HBase 模型元数据
  → 启动 FastAPI 并检查 HDFS/HBase
  → 打开 Vue 页面
  → 查看概览
  → 提交一笔订单预测
  → 查看特征重要性和规则
```

## 四、验收前检查

- [ ] 文档中的项目名称、模型名称和字段名称已统一。
- [ ] 运行命令使用真实存在的目录和脚本。
- [ ] 清洗报告中的数字来自实际执行结果，示例数字未冒充实验结果。
- [ ] 测试集和训练集没有重复订单。
- [ ] 退货发生后的字段未出现在预测请求和训练特征中。
- [ ] API 示例与 Pydantic schema 保持一致。
- [ ] 前端能够展示空数据和接口错误。
- [ ] HDFS 原始区、清洗区、训练区和模型区均有实际文件。
- [ ] HBase 订单表和模型元数据表可读写。
- [ ] 无大数据环境下可以完成本地降级演示，但不替代正式验收。

## 五、风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 退货样本比例过低 | 准确率虚高，少数类召回差 | 分层划分、报告 F1/召回率、检查混淆矩阵 |
| 退货数据无法和订单关联 | 标签不完整 | 统计无主退货，明确排除规则 |
| 类目命名不一致 | 特征碎片化 | 建立类目映射表并保留原值 |
| 决策树过深 | 训练集高分、测试集低分 | 限制深度和叶节点样本数，记录调参结果 |
| HDFS 不可用 | 无法读取批处理数据和模型产物 | 保留本地 CSV 适配器用于开发，并在健康检查中标记降级 |
| HBase 不可用 | 订单查询和模型元数据服务不可用 | 启动失败或进入明确的只读降级状态，不静默返回空数据 |
| HDFS/HBase 版本不一致 | 数据和模型无法追溯 | 所有产物写入批次号、数据版本和模型版本 |
