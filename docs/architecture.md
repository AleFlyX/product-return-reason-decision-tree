# 系统架构说明

## 一、架构概览

系统采用数据处理、特征工程、模型、后端和前端分层结构：

```text
订单表 / 退货表 / 可选 HDFS、Hive、HBase
                ↓
        数据采集与数据清洗
                ↓
      订单-退货关联与标签构造
                ↓
          特征工程 Pipeline
                ↓
       决策树训练、评估和导出
                ↓
      模型、指标、规则和分析数据
                ↓
              FastAPI
                ↓ JSON
          Vue 3 + ECharts
```

本地 CSV 是默认实现路径；大数据组件通过数据访问适配层接入，不改变模型和 API 的业务契约。

## 二、核心数据流

```text
orders_raw.csv ──┐
                 ├─→ 清洗、去重、类型转换 ─→ orders_clean.csv ─┐
returns_raw.csv ─┘                                             │
                                                               ├─→ return_model.csv
returns_clean.csv ──────────────────────────────────────────────┘
                                                                     ↓
                                                        train/test split
                                                                     ↓
                                                   preprocessing + model
                                                                     ↓
                         return_decision_tree.joblib + metrics.json + rules.json
```

`return_model.csv` 是订单级训练表，每个 `order_id` 只允许出现一次。

## 三、模块职责

| 模块 | 职责 | 输入 | 输出 |
| --- | --- | --- | --- |
| 数据采集 | 获取经授权的订单和退货数据 | 数据源 | 原始 CSV/TSV |
| 数据清洗 | 去重、类型转换、异常和缺失处理 | 原始文件 | 清洗文件、报告 |
| 标签构造 | 按订单关联退货记录 | 订单、退货清洗文件 | `returned` |
| 特征工程 | 编码、划分数据集、检查泄漏 | 训练表 | Pipeline 输入 |
| 模型 | 训练、预测、评估、规则导出 | 特征数据 | joblib、JSON、图片 |
| 数据服务 | 提供概览、分析和订单查询 | 清洗数据或适配器 | 业务统计 |
| FastAPI | 参数校验和 HTTP 接口 | 数据服务、模型 | JSON |
| Vue 3 | 页面交互、图表和错误状态 | JSON API | 分析页面 |

## 四、领域边界

### 1. 订单数据边界

订单数据描述下单时可知的事实，例如类目、价格、促销和运费。它是模型预测的输入来源。

### 2. 退货数据边界

退货数据描述下单后的售后事实，例如退货时间、退货原因和退款金额。它用于生成标签和做结果分析，不直接进入预测特征。

### 3. 模型边界

模型只负责：

- 输入标准化后的订单特征；
- 输出退货类别和概率；
- 提供特征重要性、评估指标和规则。

模型不负责保存原始退货明细，也不负责解释具体客服流程。

## 五、后端分层

```text
routers        接收 HTTP 请求并返回响应
schemas        Pydantic 请求/响应模型
services       预测、统计、规则和模型加载业务
repositories   CSV/HDFS/Hive/HBase 数据访问适配
core           配置、日志、异常、CORS
```

路由层不直接实现模型计算；预测和统计逻辑由 service 层负责。仓储层允许本地文件和大数据存储切换。

## 六、前端分层

```text
views          概览、退货分析、预测、模型解释页面
components     指标卡、图表容器、规则列表、状态提示
api            Axios 请求封装
router         路由配置
```

前端通过 `VITE_API_BASE_URL` 配置后端地址，默认开发地址为 `http://localhost:8000`。

## 七、关键设计约束

1. 训练和推理必须复用同一套预处理 Pipeline。
2. 所有分析接口同时返回样本量和统计口径，避免只展示百分比。
3. 退货率较低时，不能只看准确率，必须同时检查召回率和 F1。
4. 决策树深度和叶节点最小样本数必须记录到模型元数据。
5. API 不返回未在接口文档中声明的字段。
